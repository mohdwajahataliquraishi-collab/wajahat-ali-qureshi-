# Wajahat Ali — Creative Technologist
**AI × WEB × MOTION**

> "I don't just build websites. I create visual experiences."

A cinematic creative-technology portfolio combining real-time AI generation, 60fps canvas sequence orchestration, scroll-driven kinetic timelines, interactive 3D web experiences, and editorial typography.

---

## 🌟 Features

- **Real-Time Cursor Gaze Tracking**: The hero video/frame sequence tracks the visitor's cursor across the viewport. Moving the cursor upward elevates the subject's gaze toward 90°; moving downward returns the gaze to forward neutral (0°).
- **Smooth Spring Physics**: Interpolated `requestAnimationFrame` lerp loop for organic head and eye movements.
- **Dynamic 240-Frame Canvas Sequencer**: High-performance HTML5 `<canvas>` rendering using `SequenceManager` with zero DOM reflows and dynamic progress-to-frame mapping.
- **Project 01: "90° UPWARD"**: Scroll-driven kinetic timeline with biological constraint HUD verifying the special rule: *Body and torso remain visually frozen; only head and eyes rotate 90° upward*.
- **Selected Works**:
  - *AI Website Experiences* (Interactive generative canvas UI)
  - *Cinematic Web* (3D multi-plane spatial parallax)
  - *AI Creative Experiments* (Latent trajectory gallery & modal)
- **The Lab (Research & Experiments)**: Masonry layout featuring interactive simulations (GLSL shader noise, anamorphic aspect ratio switcher, audio-reactive visualizer).
- **Methodology & Case Study**: 6-step deep dive into concept, reference, generation, motion vectoring, refinement, and final web deployment.
- **Interactive Project Inquiry Modal & Email Copy**: Direct client brief submission flow with instant confirmation.
- **Live Configuration Drawer**: Allows live in-browser customization of brand name, tagline, introduction, accent color, and project items.

## 🛠 Tech Stack

- **Framework**: React 19 + TypeScript
- **Styling**: Tailwind CSS v4 + Custom Grain Shaders
- **Motion**: Motion (Framer Motion v12) + HTML5 Canvas API + Hardware Acceleration
- **Build Tool**: Vite 8
- **Icons**: Lucide React
- **Typography**: Syne (Display) + Plus Jakarta Sans (Body) + JetBrains Mono (Telemetry)

## 🚀 Quick Start

### 1. Clone the Repository
```bash
git clone https://github.com/<YOUR_GITHUB_USERNAME>/wajahat-ali.git
cd wajahat-ali
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:3000`.

### 4. Build for Production
```bash
npm run build
```
